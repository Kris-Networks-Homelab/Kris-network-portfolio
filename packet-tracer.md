# Cisco Packet Tracer Labs

Cisco Packet Tracer gives me a repeatable environment for network design, configuration, verification, and troubleshooting beyond the scale of my physical homelab. The work is organised as focused study labs rather than presented as a single production deployment.

## Routing & Switching Practice

- Create VLANs and assign access ports
- Configure and verify 802.1Q trunks
- Route between VLANs using router-on-a-stick
- Apply IPv4 addressing and subnetting plans
- Configure static and default routes
- Build OSPF topologies and verify learned routes

## Services & Network Access

- Configure DHCP for client addressing
- Use NAT/PAT for inside-to-outside connectivity scenarios
- Apply standard and extended ACLs to control traffic
- Troubleshoot DNS and distinguish name-resolution failures from general connectivity faults

## Wireless Concepts

- Wireless LAN design fundamentals
- Wireless LAN Controller and lightweight access point roles
- WLAN, SSID, addressing, and client-association concepts

## Troubleshooting Approach

Each lab is treated as a system to verify, not just a configuration exercise. I check physical and interface state, addressing, VLAN membership, trunks, gateways, routing information, access controls, services, and end-to-end reachability. When a fault is introduced or found, I isolate one layer at a time, correct it, retest, and document the result.
