# Packet Tracer Network Labs

This section documents enterprise-style network simulations built in Cisco Packet Tracer to develop real-world networking skills.

The labs are designed to simulate how enterprise networks evolve and are used to practice routing, switching, wireless infrastructure, and troubleshooting.

---

## Enterprise Network Simulation

A multi-phase enterprise network built in Cisco Packet Tracer covering a wide range of networking technologies.

### Technologies Covered

- VLANs
- Trunking
- Inter-VLAN Routing
- OSPF
- NAT / PAT
- DHCP
- ACLs
- Wireless LAN Controller (WLC)
- Network troubleshooting

---

### Phase 1 — Campus Core

Concepts:

- VLAN creation
- Switch trunking
- Router-on-a-stick

Status: In Progress

---

### Phase 2 — Routing Infrastructure

Concepts:

- OSPF configuration
- Multi-router design
- Route propagation

Status: Planned

---

### Phase 3 — Internet Edge

Concepts:

- NAT / PAT
- DHCP
- Default routing

Status: Planned

---

### Phase 4 — Wireless Infrastructure

Concepts:

- WLC configuration
- Access points
- WPA2 security

Status: Planned
