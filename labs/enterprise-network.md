# Enterprise Packet Tracer Network Lab

This project documents the design and staged build-out of a medium-sized enterprise network built in Cisco Packet Tracer.

The lab is designed to simulate how a real enterprise network evolves over time, incorporating switching, routing, wireless infrastructure, and security.

---

## Technologies Covered

- VLANs
- Trunking (802.1Q)
- Inter-VLAN Routing
- OSPF
- NAT / PAT
- DHCP
- Access Control Lists
- Wireless LAN Controller (WLC)
- Access Points
- Network Troubleshooting

---

## Phase 1 — Campus Core Network

Objectives:

- Create VLANs for different departments
- Configure trunk links
- Configure router-on-a-stick inter-VLAN routing

Concepts:

- VLAN segmentation
- Default gateways
- Layer 2 vs Layer 3 forwarding

Status: **In Progress**

---

## Phase 2 — Routing Infrastructure

Objectives:

- Introduce multiple routers
- Configure OSPF
- Verify routing tables

Concepts:

- OSPF neighbor relationships
- Route advertisement
- Network convergence

Status: Planned

---

## Phase 3 — Internet Edge

Objectives:

- Simulate ISP connectivity
- Configure NAT/PAT
- Provide DHCP to end devices

Concepts:

- Inside vs outside NAT
- Dynamic PAT
- Default routing

Status: Planned

---

## Phase 4 — Wireless Infrastructure

Objectives:

- Deploy a Wireless LAN Controller
- Configure Access Points
- Create internal and guest SSIDs

Concepts:

- WLC management
- Wireless VLAN mapping
- WPA2 security

Status: Planned

---

## Phase 5 — Security

Objectives:

- Implement ACLs
- Secure switch ports
- Configure SSH

Concepts:

- Standard and extended ACLs
- Port security
- Secure device management

Status: Planned
