I am a technical professional transitioning from a long trade career into network engineering. I am completing a Bachelor of Information Technology focused on Network Engineering, preparing for the Cisco CCNA, and building practical capability through a physical Cisco homelab, Cisco Packet Tracer, and Linux.

This repository presents the work behind that transition: network design, device configuration, addressing plans, infrastructure documentation, and methodical troubleshooting.

## Technical Focus

- Cisco IOS configuration and verification
- IPv4 addressing and subnetting
- VLANs, 802.1Q trunks, and inter-VLAN routing using router-on-a-stick
- Static and default routing, plus OSPF
- NAT/PAT, DHCP, DNS troubleshooting, and standard and extended ACLs
- Wireless networking fundamentals, including WLC and lightweight AP concepts
- Linux networking and structured network troubleshooting
