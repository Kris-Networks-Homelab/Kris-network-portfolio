# Skills

These skills reflect university study, CCNA preparation, physical homelab work, and Cisco Packet Tracer practice.

## Routing & Switching

- Cisco IOS configuration and verification in lab environments
- IPv4 addressing, subnetting, and address planning
- VLAN configuration and 802.1Q trunking
- Inter-VLAN routing using router-on-a-stick
- Static and default routing
- OSPF configuration, multi-area design, passive interfaces, and route verification

## Network Services & Security Fundamentals

- NAT and PAT in lab scenarios
- DHCP configuration and client addressing checks
- DNS troubleshooting as part of end-to-end connectivity diagnosis
- Standard and extended ACL configuration and testing
- Wireless networking fundamentals
- Wireless LAN Controller and lightweight access point concepts

## Troubleshooting

- Structured fault isolation: identify symptoms, narrow scope, test, correct, and verify
- Layer-by-layer checks across physical connectivity, addressing, switching, routing, and services
- Cisco IOS operational verification and routing-table interpretation
- Clear topology, addressing, and troubleshooting documentation

## Tools & Platforms

- Physical Cisco routers and Catalyst switching hardware
- Cisco Packet Tracer
- Cisco IOS
- Linux command line and networking tools
- Network diagrams, addressing tables, and repeatable lab notes

## Professional Strengths

- Practical fault-finding developed through a long technical trade career
- Methodical, safety-conscious work under real-world pressure
- Clear documentation and communication
- Teamwork, requirements analysis, and risk awareness
- Reliable follow-through and continuous hands-on learning
